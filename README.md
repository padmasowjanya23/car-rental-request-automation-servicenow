## Project Overview

**Car Rental Request Automation in ServiceNow Using Service Catalog and Workflows** is a ServiceNow-based project that automates the car rental request process from submission to approval and fulfillment.

### Project Phases

- **Phase 1 – Requirement Analysis & Planning:**
  Defined project requirements, objectives, workflow, and overall system design.
- **Phase 2 – Backend Development & Data Architecture:**
  Configured the Car Inventory table, catalog variables, Business Rules, and backend automation.
- **Phase 3 – UI/UX Development & Customization:**
  Developed and customized the Car Rental Request Service Catalog experience and user-facing components.
- **Phase 4 – Data Migration, Testing & Security:**
  Integrated the workflow with the Catalog Item and tested requests, approvals, catalog tasks, notifications, and data integrity.
- **Phase 5 – Deployment, Documentation & Final Presentation:**
  Finalized the project documentation, prepared the demo, and organized the project for presentation and deployment.

### Key ServiceNow Features Used

- Service Catalog
- Flow Designer
- Business Rules
- Catalog Tasks
- Approvals
- Email Notifications
- Car Inventory Management
- Request & RITM Tracking
- Data-driven Workflow Automation
